# comma-residue-lab

Public execution artifact of a domain-general computational methodology applied to a previously unseen problem.

**Problem domain**: multiplicative interval closure and the Pythagorean comma residual.

**Process enforced**: RESTRICT → REPRESENT → CONSTRUCT → MEASURE → RESOLVE → V&V → CERTIFY

The test is not aesthetic success. The test is whether the process itself is inspectable: intermediate structure, failed hypotheses, measurements, corrections, and residue are preserved.

See `PROBLEM.md` for the starting specification.

No protected kernel is bypassed. Negative results stay.
